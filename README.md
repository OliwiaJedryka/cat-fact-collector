Cat Fact Collector 🐱

Web application built with C# and .NET that retrieves random cat facts from the Cat Fact API and saves them locally.

Features
- Fetches a random cat fact from the Cat Fact API
- Displays the fact in the web interface
- Displays the length of the fact
- Saves each received fact to a local .txt file

Technologies
- C#
- .NET / ASP.NET Core
- HTML
- CSS
- JavaScript
- Cat Fact API
- 
How to run
1) Clone the repository.
2) Open the project folder in a terminal.
3) Run: dotnet run
4) Open the address shown in the terminal in your browser.
